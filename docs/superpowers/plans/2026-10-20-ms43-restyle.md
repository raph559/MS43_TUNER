# MS43 Tuner restyle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild every screen and window of MS43 Tuner on the approved Day (look A) / Night (look B) design system. That covers Live (readouts as Tiles or Dials), Tune (maps and every item kind), Compare, a new Settings dialog, the save prompt, the connection log and the Performance tests window. Behaviour stays as it is apart from the listed settings and fixes.

**Architecture:**
- Core gets the small rules that do not depend on the UI: number and dash rules, edit limits, the map colour range with its storage-limit outliers, save options, and a structured retry event on the logger.
- The app gets one token dictionary, one style sheet, one stroke icon set and one map colour ramp. Every screen is then rebuilt on them, one screen per task.
- Settings, the save prompt and the connection log become in-window overlays hosted by a `DialogHost` in the main window, not OS windows. Only an in-window overlay can draw the spec's scrim (system 4.3), its radius 12 and the Day shadow. Performance tests stays a separate, non-modal window.
- The legacy resource keys and style classes stay as aliases until Task 15 removes them. The app therefore builds and its tests pass after every task.

**Tech Stack:** C#/.NET 10, Avalonia 11.3.12 (FluentTheme base), xUnit 2.5.3, Avalonia.Headless.XUnit 11.3.12 (real Skia pixels).

**Spec:** `docs/superpowers/specs/2026-10-20-ms43-restyle-design.md` and its binding companion `docs/superpowers/specs/2026-10-20-ms43-restyle-system.md` ("system" below).
- Every visual value (hex, size, radius, copy) comes from the system. This plan names the files, members and tests, and makes the decisions the spec leaves open.
- **Visual references:** `.superpowers/design/2026-10-20-restyle/clean/*.html` and their renders in `clean/png/`. They are local and untracked, hold the owner's car data, and are never committed.

## Global Constraints

- `net10.0`, Avalonia 11.3.12, FluentTheme as the base. No new NuGet packages.
- Never open a window on the owner's desktop.
  - Every UI check is a headless test (`Avalonia.Headless.XUnit`, `UseHeadlessDrawing = false`).
  - Renders go through `Screens.Save` to `artifacts/screens/`.
- Tests never open a serial port and never write the original bins.
  - They work on copies (`TuneScreen.CopyCar`, `testdata/local`).
  - They drive connection states through the view model's report methods.
- Logging behaviour does not change: the same telegrams, the 20 ms pause, the stop after 3 timeouts in a row (`LiveLogger.TimeoutLimit`), and the CSV columns.
- antislop applies in "during" mode (the owner's standing preference).
  - Tasks 5 to 14 each end Step 4 by adding that screen's Delivery Gate to `.superpowers/antislop/delivery-gate-build.md` (local, untracked). The gate covers core Blocks 1 to 4 and the UI and Human checklists, with one line of evidence per item. Task 15 completes the report.
  - Check every colour pair that system 1.2, 2.1 or 2.5 does not already list with `contrast-check.py` from the antislop-human skill: `python contrast-check.py "#FG" "#BG"`.
- Copy rules (system 9):
  - sentence case;
  - no U+2014 or U+2013 in any UI string, and U+2212 only in the label "B − A";
  - numbers use the ASCII "-", no digit grouping, and "n/a" when missing;
  - "number space unit";
  - the ellipsis character "…" for commands that open a dialog or picker and for statuses in progress, never "...".
- Orange (`Now` / `NowText`) appears only on the marks listed in system 1.4. An idle screen shows no orange.
- Fonts:
  - `UiFont` = Segoe UI Variable Text, then Segoe UI;
  - `DataFont` = Bahnschrift, with `+tnum` on every number;
  - `MonoFont` = Cascadia Mono;
  - Inter (bundled) is the last fallback for all three.
- Long text truncates and keeps its full value in the tooltip. Both trimming modes below exist in Avalonia 11.3.12.
  - File names keep their start and end: `TextTrimming.PrefixCharacterEllipsis`.
  - Paths keep their end: `TextTrimming.LeadingCharacterEllipsis`, as in "…\ms43-20261019-2225.csv".
- Tests that pin old styling or copy are updated in the task that changes that styling. They are never deleted without a replacement test.
- Do not touch `README.md` (another session's edit). Commit only when the owner says so, with no AI co-author trailer.

## Review Focus

- **Theme switched while a grid, dial, chart, glyph or sparkline is on screen:** every custom-drawn control repaints in the new theme (ItemGlyph does not today). Test in Task 3.
- **Long bin, XDF, CSV or channel names at the 1024 × 680 minimum:** text truncates with an ellipsis, the full text is in the tooltip, and nothing extends past the window. Tests in Tasks 5 and 15.
- **A shortcut pressed while a dialog is open** (Ctrl S, Ctrl Z, Ctrl O, Ctrl K or Ctrl , behind Settings or the save prompt): nothing happens behind the dialog, and Esc closes only the dialog. Test in Task 6.
- **Disconnect and reconnect within the same second, or a log folder that does not exist yet:** a new log never overwrites an earlier one, and the folder is created. Tests in Task 12.
- **Live value missing or outside its scale** (rpm 9000 on a 0 to 8000 scale, advance below -30, gear 0):
  - the readout prints the true number;
  - the mark clamps at the end of its scale;
  - a missing value or gear 0 reads "n/a" with no fill.

  Test in Task 11.

**Interfaces:**
- Produces:
  - `ValueCodec.Format` returns "n/a" for NaN (was U+2014).
  - `BinComparer.FormatDelta(double delta, long rawDelta, XdfZ z, bool raw)`, signature unchanged:
    - non-zero: "+1.50" / "-0.38" with the ASCII minus; hex and ASCII items give "+4" / "-4";
    - zero: zero in the item's own format ("0.00" at 2 decimals, "0" for hex), replacing "·";
    - NaN: "n/a".
  - `ComparisonText`:
    - ranges read "0x03C43 to 0x03C9B";
    - counts have no grouping: `Count` drops "N0", giving "11907 bytes".
  - `BinImage.Load` refuses a wrong size with "{name} is {n} bytes. An MS43 bin is exactly 524288 bytes (512 KiB)." The UI puts "Not opened: " in front (Tasks 7 and 13).
  - `TableClipboard.Format` writes "n/a" for a cell that is not finite.
  - `public sealed record EditLimits(double StorableMin, double StorableMax, double? Step, double? XdfLow, double? XdfHigh)`, with `public static EditLimits For(ValueCodec codec, XdfMath math, XdfData data, double? xdfLow, double? xdfHigh)`:
    - The storable range is the physical range over the raw domain of `data`. For a non-linear equation it is found by a scan, as `ValueCodec.ToRaw` already does.
    - `Step` is `|phys(r + 1) - phys(r)|` when it is the same at both raw ends and in the middle; otherwise it is null.
    - `XdfLow` and `XdfHigh` keep only an XDF end that narrows the storable range. Tables pass `XdfZ.Min` / `Max`; constants pass `RangeLow` / `RangeHigh`.
  - `public sealed record MapColourRange(double Min, double Max, IReadOnlySet<(int Row, int Col)> Hatched)`:
    - `bool IsConstant => Min == Max`;
    - `static MapColourRange Compute(double[,] physical, long[,] raw, long rawMin, long rawMax)`;
    - `static MapColourRange Compute(TableValues values)`, which takes the raw limits from `values.Table.Z.Data`.
    - Rule (system 2.2): handle each limit group (the cells at `rawMin`, the cells at `rawMax`) on its own. Hatch the group when both hold:
      - it has fewer than half the cells;
      - its value lies outside the range of the other cells, by more than 0 and by at least a quarter of that range.
    - Min and Max come from the cells that are not hatched.
