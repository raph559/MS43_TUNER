# MS43 Compare Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compare the open bin (A) with a second bin (B) item by item through the same XDF: list what differs, show a table as A, B and B − A grids, list the raw bytes that differ outside every XDF item, copy an item from B into A with undo, and print the same list from the CLI with `diff`.

**Architecture:** The comparison is UI-free code in `MS43Logger.Core.Tuning` (`BinComparer`, `ComparisonText`, `TableEdits.CopyFrom`), built test-first on the real car and release bins. The app gets a third tab, Compare, driven by a `CompareViewModel` that holds B and reuses `MapGrid` (through read-only `TableEditorViewModel`s) with a new diverging shading for B − A. Copying goes through A's `EditHistory`, so undo, the unsaved count, save, `.bak` and the edit log all work unchanged.

**Tech Stack:** C#/.NET 10, Avalonia 11.3.12, xUnit, Avalonia.Headless.XUnit 11.3.12 (tests only). No new packages.

**Spec:** `docs/superpowers/specs/2026-10-19-ms43-tuning-design.md` — goal 4, §6.4 (rail filter "differs from compare bin"), §6.5 (Compare tab), §6.7 (CLI `diff`), §8 (compare test). **Visual reference:** the Compare screen of the approved mockup, `docs/superpowers/mockups/ms43-tuner-mockup.html` (`.cmp*`, `.diff`, `.banner`, `.vs`, `.legend.div`, `renderCompareMain`).

## Decisions taken in this plan (open to veto at review)

- **Delta direction is B − A** (spec §6.5 and the task), shown as "B − A"; positive = B higher. The mockup's "A − B" label is not followed. Scalars read "A → B".
- **Diverging colours use the theme tokens `DownBrush` / `UpBrush`** (Night `#4C8DFF` / `#FF5C7A`, Day `#2E6BE0` / `#DD3B5C`) around `PaneBrush`, as the approved mockup and the tune-UI plan's token list do. Spec §5's `#5B8DEF` / `#E5675A` predates the mockup; one palette for the whole app wins. Negative (B lower) = blue, positive (B higher) = coral.
- **One grid at a time** with a segmented switch `B − A` (default) / `A` / `B`, as in the mockup: three 20 × 16 grids side by side do not fit at 1440 px.
- **List grouping:** kind chips with counts (All, Maps, Curves, Axes, Values — Values covers values, switches and flags), then the rows grouped under category headers like the Tune rail. Each item appears once, under its first category (the rail repeats multi-category items; a diff list should not double-count).
- **Copy B into A copies a whole item** (table, value, switch, or the one flag bit). Bytes outside the XDF are listed, never copied (boot block, service sector).
- **B is remembered** in settings (`LastCompareBin`) and reopened when the Compare tab is first shown, if the file still exists.
- **CLI exit code:** 0 when the comparison ran (whatever it found), 1 on error, like `show`.

## Review Focus

- **B is a different firmware or a wrong-size file** (stock 430069 bin against the MS43X001 XDF, or a 256 KiB dump): wrong size is refused with a message and A stays open; different firmware compares at the same addresses with a warning naming both firmwares — tests in Tasks 1 (CLI) and 5.
- **A is edited after the comparison** (on the Tune tab, by undo, or by Copy B into A): the list and grids are recomputed before they are shown again, and an item copied from B disappears from the list — tests in Task 5.
- **Copying an item whose data the XDF marks unsupported, or a flag that shares its word with other flags:** unsupported is refused with a message and no byte changes; a flag copy changes only its own bit — tests in Task 2.
- **A table whose cells are equal but whose linked axis differs**: the axis table itself is listed; a table listed for its own cells names every differing axis — test in Task 1.
- **Identical bins:** "No differences" in the list and the CLI, no exception on empty lists — tests in Tasks 1 and 5.

```csharp
public sealed record AxisDifference(string Direction /* "row" | "column" */, AxisValues A, AxisValues B)
{
    /// "The row axis differs (ldpm_n_14, rpm): A runs 800 to 6990, B 600 to 6500, so cells are compared position by position."
    public string Describe();
}

public sealed record TableComparison(TableValues A, TableValues B, TableValues Delta,
    IReadOnlySet<(int Row, int Col)> Changed, IReadOnlyList<AxisDifference> Axes, double? LargestChange);

public sealed record ItemDifference(XdfItem Item, ItemKind Kind, string Category, int ChangedCells, int Cells,
    double? LargestChange, string? ValueA, string? ValueB, IReadOnlyList<AxisDifference> Axes);

public sealed record UnmappedRange(int Offset, int Length, string Area);

public sealed record BinComparison(IReadOnlyList<ItemDifference> Items, IReadOnlyList<UnmappedRange> Unmapped)
{
    public int UnmappedBytes { get; }   // sum of lengths
    public bool IsEmpty { get; }
}

public static class BinComparer
{
    public static BinComparison Compare(XdfDefinition xdf, BinImage a, BinImage b);
    public static TableComparison CompareTable(XdfDefinition xdf, BinImage a, BinImage b, XdfTable table);
    public static string AreaName(int offset);
    /// Signed text for a B − A cell: "+1.50", "−0.38", "·" for zero; outputtype 2 → integer, 3/4 → decimal like 1.
    public static string FormatDelta(double delta, long rawDelta, XdfZ z, bool raw);
}

public static class ComparisonText
{
    public static string Format(BinComparison comparison, string nameA, string nameB, string xdfName);
}
```

Rules the tests pin:
- An item differs when any byte of its data differs (flags: only its own `Mask` bits). Items whose data lies outside the image are skipped. Unsupported data is compared on raw values; its `LargestChange` is null.
- `LargestChange` = the signed physical B − A with the largest magnitude; `ValueA`/`ValueB` for values = `ConstantValue.Display`, for switches the matching choice label (else the display), for flags `"on"`/`"off"`; tables leave them null.
- `Axes` lists a table's row/column axis when its physical values differ between A and B (NaN equals NaN); computed for listed tables only.
- `Category` = the item's first category name, `XdfCatalog.OtherCategory` when none. `Items` ordered by category (ordinal-ignore-case), then title.
- `Unmapped` = `a.DiffRanges(b)` minus every byte covered by a table's Z data, an axis's own `Data`, a constant or a flag; split at area boundaries; adjacent survivors merged. Areas by file offset: `0x00000` Boot block, `0x04000` Unused, `0x08000` Service sector, `0x0C000` Unused, `0x10000` Program, `0x6C000` Program constants, `0x70000` Calibration (from `MS43LAB/REPORT.md` §2).
- `Format` prints a header (A, B, XDF, "N items differ, M byte ranges (K bytes) outside the XDF"), then each category as a heading with indented rows `title  kind  changed of cells  largest ±x units` / `title  kind  A → B units` and an `axis differs: row (name)` note, then "Bytes outside the XDF" rows `0x03C43–0x03FBB  377 bytes  Boot block` (inclusive end, five hex digits). Identical bins print `No differences.`
